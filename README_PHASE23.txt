SIF Mobile & Computer — PHASE 23
Catalog Management: Categories & Product Types

1. Run START_SIF.bat.
2. Login admin / admin.
3. Open Back Office / Settings.
4. Categories: add/edit/delete and upload category image.
5. Product Types: add/edit/delete.
6. Add Product loads live Categories and Product Types into the combo boxes.
7. Edit Product can change Category/Type and delete the product photo.
8. Existing built-in categories/types are seeded automatically.
