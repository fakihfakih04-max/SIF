SIF Mobile & Computer - PHASE 18

IMPORTANT: This version uses port 8017 so it cannot accidentally open an older SIF server running on port 8000.

START:
1. Close all old SIF browser windows and old SIF CMD/server windows.
2. Run START_SIF.bat.
3. Use the browser opened at http://127.0.0.1:8017/

PRICE CHECKER:
Retail = ONLY Retail price + USD + LBP.
Wholesale = ONLY Wholesale price + USD + LBP.
VIP = ONLY VIP price + USD + LBP.
No combined Retail/Wholesale/VIP line is shown.

PURCHASE:
Walk-in Supplier or named Supplier, product, automatic cost, quantity, VAT ON/OFF, payment, official purchase number, stock increase.

This package intentionally removes the obsolete script1.js price checker to prevent the old combined-price UI from being used.
