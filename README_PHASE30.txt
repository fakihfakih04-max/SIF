PHASE 30 - PRODUCT EXCEL IMPORT / EXPORT

Products now supports:
- Export all active products to SIF_Products.xlsx
- Download Excel import template
- Import .xlsx/.xlsm
- Existing SKU is updated; new SKU is created
- Imported Category/Type are created automatically if missing, so they appear in Add Product combos
- Columns: SKU, Barcode, Name, Category, Type, Cost, Retail Price, Wholesale Price, VIP Price, Quantity, Reorder Level, Warranty Months, IMEI Required, Serial Required, Photo URL

Run START_SIF.bat. Requires openpyxl; the launcher installs backend requirements.
