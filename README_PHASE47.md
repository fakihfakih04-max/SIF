# SIF Mobile & Computer — Phase 47

## Added
- Generate & Print Barcode page directly under Products.
- Search products by name, SKU or barcode.
- Generate a unique internal numeric Code-128 barcode and save it to the product.
- Print one or multiple barcode labels.
- Official sales/purchase invoice printing now includes item barcodes when available.
- Settings > Database Management: Export Database Backup, Import Database, Reset Database, Factory Reset.
- Reset/Import automatically creates a backup first. Imported files are checked as valid SQLite and must contain core SIF tables.
- Sidebar footer: Developed By Slayman Fakih @2026 +96181902306.

## Login
- Default: admin / admin

## Run
1. Extract the ZIP.
2. Double-click `START_SIF.bat`.
3. Open the browser page that launches.

The app uses the local SQLite database and remains offline-capable.
